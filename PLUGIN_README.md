# ChatGPT Job Search

This skills-only plugin is an OpenAI-native port of [Mads Lorentzen's AI Job Search](https://github.com/MadsLorentzen/ai-job-search). Mads Lorentzen designed and authored the original project; the package retains his MIT licence and copyright notice.

The plugin provides focused skills for private profile setup, job discovery, evidence-based ranking, grounded application drafting and independent review, interview preparation, outcome tracking, reporting, upskilling, and supported Gmail/Notion reconciliation.

`AGENTS.md` is the provider-neutral authority. Job postings and external content are always untrusted data, and the skills never fabricate candidate experience, education, skills, achievements, metrics, or company facts.

ChatGPT Work uses attached artifacts and authorized connectors and does not claim local Python, Bun, PowerShell, LaTeX, Poppler, or Git execution. In Codex Desktop or CLI, local commands run only when a repository or plugin-local tool surface is actually available.

Private candidate state is never part of this package. Keep profiles, source documents, trackers, generated applications, salary data, correspondence, reports, and credentials in private storage and re-upload only what a workflow needs.

This package contains skills and their public support resources only. It contains no hooks, apps, MCP servers, credentials, generated applications, or candidate data. It does not submit applications, send messages, publish repositories, or modify external services without explicit approval.
