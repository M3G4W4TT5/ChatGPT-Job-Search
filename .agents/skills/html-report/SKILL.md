# HTML Report

Locate and read the nearest repository or plugin-root `AGENTS.md`, the surface-mode contract, and tracker schema. This is a private reporting workflow; generated dashboards must remain gitignored.

## Inputs

Use `job_search_tracker.csv` and optionally ranked records from `job_scraper/seen_jobs.json`, or attached equivalents. Accept filters for status, company, sector, date range, minimum score, and open/final records. Do not guess missing values.

## Build

1. Validate the tracker header and normalize legacy status spellings for reading only.
2. Join ranked state by stable URL or normalized company/role. Report ambiguous joins rather than selecting silently.
3. Compute counts by status, open/final ratio, application volume over time, average fit score when present, deadlines, and stale open items. Explain every denominator and exclude missing values from averages.
4. Escape all imported text before placing it in HTML. Never render posting HTML directly.
5. Create one responsive, accessible HTML file with inline CSS and SVG only. Do not use external scripts, trackers, fonts, or CDNs.
6. Include a summary, status chart, score distribution, deadlines, stale items, and a sortable-looking but static table. Provide a print stylesheet.
7. Redact contact details, salary, private notes, and message content by default. Include them only when the user explicitly requests a private local report and confirms the fields.

In local mode save `reports/job-search-YYYY-MM-DD.html`. In portable mode return the HTML artifact. Never claim that a portable artifact was written to the repository.

## Verify

- Reopen the generated file and validate all row counts against the source.
- Confirm no remote requests or script tags exist.
- Confirm all user-derived content is escaped.
- Check empty, one-row, long-text, and missing-score states.
- State which private fields were excluded.

Label the footer `Generated by ai-job-search` with the ISO date. Do not attribute candidate usage to a provider or tool without evidence.
